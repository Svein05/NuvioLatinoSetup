6. Cómo Obtener tus API Keys Gratuitas

Para que Nuvio y AIOMetadata sincronicen sinopsis oficiales en español latino, ratings de IMDb/Rotten Tomatoes y carátulas personalizadas, se requieren dos claves gratuitas obligatorias. Sigue estas guías paso a paso:

TMDB API Key

100% Gratuita • Personal

Obligatoria
  1. Abre themoviedb.org/signup y crea tu cuenta gratuita.
  2. Verifica tu correo electrónico con el link que te enviarán.
  3. Inicia sesión y dirígete a Configuración de API.
  4. Haz clic en "Crear" o "Solicitar clave API" y selecciona la opción "Desarrollador".
  5. Acepta los términos e indica que es para uso personal en Nuvio.
  6. Copia la Clave de la API (v3 auth) (32 caracteres alfanuméricos) y pégala en el Paso 4.
Ir a Ajustes de API en TMDB

MDBList API Key

100% Gratuita • Calificaciones

Obligatoria
  1. Abre mdblist.com e inicia sesión gratis con tu cuenta de correo, Trakt o Patreon.
  2. Una vez dentro, ve a las Preferencias de Perfil en la esquina superior.
  3. Desplázate hacia abajo hasta la sección etiquetada como "API Key".
  4. Si es tu primera vez, haz clic en el botón para generar tu clave; si ya existe, haz clic en copiar.
  5. Pega tu clave en el campo MDBList API Key del Paso 4 de nuestro asistente.
