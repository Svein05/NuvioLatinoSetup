Visión General

1. ¿Qué es Nuvio Latino Setup?

Nuvio Latino Setup es una suite web desarrollada para resolver la fragmentación y falta de localización en Nuvio TV. Por defecto, instalar Nuvio y addons de catálogos genera decenas de filas desordenadas en inglés, carátulas cuadradas genéricas y saturación en la pantalla principal.

Esta herramienta actúa como un orquestador inteligente que vincula tu perfil de Nuvio con una instancia optimizada de AIOMetadata, inyectando colecciones nativas agrupadas en formato panorámico 16:9 de carga ultrarrápida (0 ms) con metadatos en Español Latino oficial (es-MX).

Seguridad y Privacidad Garantizada

La aplicación es 100% estática (frontend puro ejecutado en tu propio navegador). Tus credenciales de Nuvio viajan cifradas directamente hacia los servidores de Supabase de Nuvio (api.nuvio.tv). Ningún servidor de terceros interviene ni almacena datos sensibles.

2. Requisitos Previos

Para completar la configuración en menos de 2 minutos necesitas disponer de:

Cuenta de Nuvio TV

Tu correo y contraseña registrados en Nuvio. Si no tienes cuenta o no deseas conectarla, puedes usar el Modo Manual.

TMDB API Key (Obligatoria)

Clave de API de The Movie Database. Es gratuita, inmediata y requerida para activar los pósters y sinopsis en español latino (es-MX).

MDBList API Key (Obligatoria)

Clave de MDBList para habilitar calificaciones agregadas (IMDb, RT, Metacritic, Trakt) y sustentar motores dinámicos de pósters.

3. Guía del Asistente en 6 Pasos

1

Paso 1: Conexión con Cuenta de Nuvio

Ingresa tu correo y contraseña para autenticarte contra la API oficial de Nuvio. Si eres nuevo en Nuvio, puedes cambiar a la pestaña "Crear Cuenta". O si prefieres no conectar tu cuenta, haz clic en "Continuar sin cuenta (Modo Manual)" para generar los JSONs de configuración.

2

Paso 2: Selección o Creación de Perfil

El asistente descargará tus perfiles de Nuvio. Recomendamos pulsar en "Nuevo Perfil" (ej. "Latino") para no sobreescribir tus configuraciones previas, aunque también puedes elegir tu perfil Principal si deseas limpiarlo.

3

Paso 3: Gestor Visual de Colecciones (Mini Nuvio)

El simulador en vivo te permite reordenar secciones y filas por arrastre (drag & drop) o con saltos rápidos al cielo y al fondo, activar o desactivar plataformas (Netflix, HBO Max, Disney+, Prime Video, Anime) y géneros, y organizar los catálogos de cada fila de forma instantánea mediante cápsulas movibles sin esperas de carga.

4

Paso 4: Proveedores de Metadatos y Validación (API Keys)

Ingresa tu TMDB API Key y tu MDBList API Key (ambas obligatorias para asegurar metadatos oficiales en español latino es-MX, calificaciones críticas y motores de pósters). Opcionalmente puedes configurar tus claves de RPDB, TheTVDB y habilitar la Búsqueda Inteligente con IA (Gemini u OpenRouter). Finalmente, haz clic en "Probar Claves API" para validar su conectividad antes de continuar.

5

Paso 5: Preferencias de Perfil y Sistema de Pósters

Decide si activar TMDB Enrichment y calificaciones globales de MDBList en tus aplicaciones de Nuvio (si las desactivas, quedan estrictamente deshabilitadas en tu perfil). Además, elige el sistema de pósters que prefieras: AioMetadata (carátulas limpias directas de TMDB), BetterPoster (estilo minimalista con logos en es-MX) o Poster+ (calificaciones mixtas Letterboxd/Trakt y bandas cinemáticas), con previsualización sincronizada y botones directos para personalizar en sus respectivas webs oficiales.

6

Paso 6: Seguridad e Inyección Automatizada

Define una contraseña para proteger tu addon de AIOMetadata (o genera una aleatoria). Haz clic en "Ejecutar Configuración Automática". El sistema limpiará las colecciones previas del perfil, creará el manifiesto en AIOMetadata con la configuración elegida y registrará las colecciones 16:9 en Nuvio en cuestión de segundos.

Arquitectura Exclusiva

4. ¿Qué es el "Ghost Mode" de AIOMetadata?

Uno de los problemas más comunes al usar AIOMetadata es que el addon instala decenas o cientos de catálogos individuales en la pantalla de inicio de Nuvio (Trending Trakt, Recomendaciones, Populares, Géneros en inglés, etc.), saturando la interfaz.

La técnica Ghost Mode consiste en configurar todos los catálogos raíz de AIOMetadata de forma invisible para la pantalla principal de Nuvio. De este modo:

  • Los catálogos siguen existiendo y funcionando para abastecer a tus Colecciones Nativas de Nuvio.
  • La pantalla de inicio de Nuvio queda 100% limpia, mostrando únicamente tus carátulas 16:9 ordenadas.
  • Cero duplicados y carga inmediata al abrir la app en Smart TV o móvil.
Tutoriales Rápidos (1 Minuto)

5. Cómo Obtener tus API Keys Gratuitas

Para que Nuvio y AIOMetadata sincronicen sinopsis oficiales en español latino, ratings de IMDb/Rotten Tomatoes y carátulas personalizadas, se requieren dos claves gratuitas obligatorias. Sigue estas guías paso a paso:

TMDB API Key

100% Gratuita • Personal

Obligatoria
  1. Abre themoviedb.org/signup y crea tu cuenta gratuita.
  2. Verifica tu correo electrónico con el link que te enviarán.
  3. Inicia sesión y dirígete a Configuración de API.
  4. Haz clic en "Crear" o "Solicitar clave API" y selecciona la opción "Desarrollador".
  5. Acepta los términos e indica que es para uso personal en Nuvio.
  6. Copia la Clave de la API (v3 auth) (32 caracteres alfanuméricos) y pégala en el Paso 4.
Ir a Ajustes de API en TMDB

MDBList API Key

100% Gratuita • Calificaciones

Obligatoria
  1. Abre mdblist.com e inicia sesión gratis con tu cuenta de correo, Trakt o Patreon.
  2. Una vez dentro, ve a las Preferencias de Perfil en la esquina superior.
  3. Desplázate hacia abajo hasta la sección etiquetada como "API Key".
  4. Si es tu primera vez, haz clic en el botón para generar tu clave; si ya existe, haz clic en copiar.
  5. Pega tu clave en el campo MDBList API Key del Paso 4 de nuestro asistente.
Ir a Preferencias en MDBList

6. Modo Cloud Automático vs Modo Manual

Modo Automático (Nuvio Cloud)

  • • Inicias sesión con tu cuenta de Nuvio directamente.
  • • El asistente crea el perfil, inyecta las colecciones y configura el addon en 1 solo clic.
  • • Ideal para Smart TV, Fire TV Stick, Google TV y dispositivos Android/iOS.

Modo Manual (JSONs)

  • • No requiere ingresar ninguna contraseña de Nuvio.
  • • Permite personalizar todas las filas y descargar o copiar los archivos JSON generados.
  • • Puedes importar los JSONs manualmente en tu cliente de Nuvio cuando gustes.

7. Preguntas Frecuentes y Troubleshooting

¿Qué hago si falla la validación de claves en el Paso 4?

Asegúrate de que no haya espacios en blanco antes o después de la TMDB API Key. Recuerda que la clave v3 tiene aproximadamente 32 caracteres. Puedes probar abriendo la URL de prueba en tu navegador: https://api.themoviedb.org/3/authentication?api_key=TU_CLAVE.

¿Dónde obtengo soporte técnico de la comunidad?

Puedes ingresar a nuestro canal oficial de Discord en discord.gg/EubYtJVJEc para resolver cualquier duda sobre Nuvio y el addon LAT-ADD.
