# Instrucciones base de Nuvio Setup

Antes de analizar, planificar o editar, leer [docs/development/context.md](docs/development/context.md).
Es la fuente única de contexto, roadmap, Git Flow y arquitectura para todo el repositorio.
Leer también cualquier AGENTS.md más cercano a los archivos afectados.

- Mantener la tarea en su subrama; actualmente codex/mega-refactor.
- No hacer commits de trabajo ni push directos a main/master.
- No fusionar a develop ni a producción, publicar o desplegar sin autorización explícita.
- No eliminar subramas sin petición expresa.
- Migrar responsabilidades con pruebas; no borrar js/ mientras tenga consumidores.
- Actualizar únicamente context.md para el contexto de la IA; no crear memorias paralelas.

Esta entrada breve permanece en la raíz para el descubrimiento automático de Codex.
Las instrucciones explícitas del usuario prevalecen sobre las reglas del proyecto.
