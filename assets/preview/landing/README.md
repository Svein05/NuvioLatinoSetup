# Landing artwork sources

These fixed presentation assets use the same poster providers and badge pack available in the configuration wizard. They require no browser API credentials or runtime provider requests.

- `inception.jpg`: [TMDB poster](https://image.tmdb.org/t/p/w500/ljsZTbVsrQSqZgWeep2B1QiDKuh.jpg), Inception / El Origen, TMDB movie 27205, IMDb tt1375666.
- `inception-betterposter.jpg`: [BetterPoster rendering](https://btttr.cc/poster/imdb/poster-default/tt1375666.jpg?lang=es-MX&rs=IM), captured on 2026-10-22. Ratings and artwork are a fixed rendering, not a live rating feed.
- `4k-gold.png`, `remux-gold.png`, `latino.png`: [kingsizew/badges](https://github.com/kingsizew/badges), using the resolution, quality and language images referenced by the wizard's Tinted pack.

Artwork and badge rights remain with their respective owners. The project's MIT license does not relicense third-party artwork. Keep these source credits when replacing or updating the assets.
