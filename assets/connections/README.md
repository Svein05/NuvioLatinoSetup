# Carátulas de conexiones

Imágenes aportadas para las colecciones de Trakt, Simkl, AniList y MyAnimeList.
Se normalizaron los nombres a minúsculas y el formato a WebP, conservando su
proporción cuadrada y sin ampliar las imágenes pequeñas. El tamaño máximo es 512 px.

El asistente usa los recursos locales en Mini Nuvio. Las exportaciones usan sus
direcciones públicas del repositorio para que Nuvio pueda cargarlas fuera de esta web.
